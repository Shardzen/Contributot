# Circulation de l'information

Ce tableau précise, pour chaque type d'information du projet, qui la produit,
qui la valide, et où elle est stockée.

| Type d'information              | Qui produit                  | Qui valide                          | Où c'est stocké                  |
|----------------------------------|-------------------------------|--------------------------------------|------------------------------------|
| Spécifications / besoins         | Le membre à l'origine du besoin | L'autre membre, en discussion        | Issue GitHub                       |
| Bugs                              | Celui qui constate le bug     | Le dev assigné, en clôturant l'issue | Issue GitHub (template bug_report) |
| Code                              | Le dev assigné                | L'autre membre, en revue de PR       | GitHub (dépôt, branche, PR)        |
| Documentation technique          | Le dev assigné à la tâche     | L'autre membre, en revue de PR       | Dépôt GitHub (fichiers `.md`)      |
| Décisions d'équipe               | Les deux membres, en discussion | Les deux membres (accord mutuel)   | Issue ou PR GitHub (commentaires)  |
| Avancement des tâches            | Le dev assigné                | L'autre membre, via le board         | GitHub Projects (board)            |
